# Data and third-party material

This repository contains observed canonical rule data, publication metadata,
and project-authored documentation and artwork. DynamicRule's original blue
crown artwork and documentation retain the MIT notice in `LICENSE`.

It does not distribute captured OnlyFans JavaScript bundles, upstream generator
source, browser binaries, or runtime dependencies. Fingerprints identify an
observation without redistributing the captured source. The project license
does not grant rights to OnlyFans software, account data, or media.

OnlyFans is a third-party name used to describe the compatibility target.
DynamicRule and Fanclan are independent of OnlyFans.
